# Fin — 素材生成用プロンプト（ChatGPT / 画像生成）

作成: 2026-08-02
用途: 画面デザインに入る前に、アプリアイコンとタスクアイコンを先に作る。

## 順番（この順で作ると崩れない）

1. **カラーパレットを決める** ← 最初にこれ。以降すべての素材がこれに従う
2. **アプリアイコン**（ストア用・1枚）
3. **タスクアイコン**（まとめて生成）
4. 素材を添付して画面デザインへ（`design-prompts.md`）

---

## 0. カラーパレット

先に色を決めておくと、以降の素材がすべて揃う。逆にこれを後回しにすると全部作り直しになる。

```
iOSアプリ「Fin」のカラーパレットを提案してください。

アプリの内容: タスクに所要時間を入れると「全部終わる予定時刻」が表示されるタスク管理アプリ。主なユーザーはADHD当事者と先延ばしに悩む人。

世界観: 「責めない」。急かさない、煽らない、減点しない。静かで余白があり落ち着いている。
名前のFinは映画の終わりに出る「Fin」から。静かな余韻。

条件:
- ダークモードを基本とする。ライトモードも対応
- 警告色（赤）を主要な位置に使わない。未達を責める配色にしない
- 「終わる予定時刻」の数字を最も目立たせるアクセントカラーが1色必要
- 金融アプリに見えない（Finという名前から金融を連想されやすいので、そこを打ち消す色）
- タスクに割り当てる色として、識別しやすく喧嘩しない6〜8色のセット

3パターン提案し、それぞれHEXコードと使いどころを示してください。
色見本を並べた画像も出してください。
```

---

## 1. アプリアイコン

App Storeとホーム画面に出る1枚。**金融アプリに見えないこと**が必須条件。

```
iOSアプリのアイコンをデザインしてください。1024x1024px、正方形、角丸なし（iOSが自動で角丸にするため）。

アプリ名: Fin
内容: タスクに所要時間を入れると「全部終わる予定時刻」が表示されるタスク管理アプリ

コンセプト: 名前のFinは、映画の最後に出る「Fin」から来ている。終わりの静かな余韻。
「終わる」ことを、達成でも締切でもなく、静かに訪れるものとして表現したい。

必須条件:
- 金融・銀行・投資アプリに見えないこと（Finという名前から金融を連想されやすい）
- 急かす印象を与えないこと（砂時計、警告、赤い時計などは避ける）
- ホーム画面で小さく表示されても識別できること
- 文字を入れる場合は「Fin」のみ。日本語は入れない

避けるもの: チェックマーク（ありふれている）、砂時計（急かす）、リスト（地味）、ラマ・動物

方向性を3つ、それぞれ異なるアプローチで出してください:
A. タイポグラフィ中心（Finの文字そのものをアイコンにする）
B. 抽象図形（終わり・余韻を図形で表現）
C. 時刻の表現（時計ではない形で「終わる時刻」を示す）

カラーパレットは以下を使用してください:
[ここに決定したパレットのHEXコードを貼る]
```

## 2. タスクアイコン（まとめて生成）

**必ずまとめて生成すること。**1個ずつ作るとスタイルが破綻する。

### 共通の指定（各バッチの先頭に貼る）

```
iOSアプリ用のアイコンセットを作ってください。

重要: 1枚の画像に、指定したアイコンを均等なグリッドで並べて出力してください。
1個ずつではなく、まとめて生成することでスタイルを統一したいです。

スタイル指定:
- フラットデザイン、線画ではなく塗り中心
- 角の丸い、やわらかい形
- 1アイコンにつき2〜3色まで
- 背景は透明
- すべてのアイコンで線の太さ・余白・パースを完全に揃える
- 細部を描き込まない。小さく表示されても分かる単純な形
- 絵文字っぽくしない。アプリのUIパーツとして成立する品位

世界観: 静かで落ち着いている。かわいすぎず、硬すぎない。急かさない。

カラーパレット（この中だけを使う）:
[ここに決定したパレットのHEXコードを貼る]
```

### バッチ1: 朝の支度（3×3で9個）

```
以下9個のアイコンを、3×3のグリッドで1枚に並べて生成してください。

1. 起きる（ベッドから起き上がる）
2. 歯をみがく（歯ブラシ）
3. 顔を洗う（水）
4. 着替える（服）
5. 朝ごはん（お皿とフォーク）
6. 髪をととのえる（くし）
7. 薬をのむ（錠剤）
8. 家を出る（ドア）
9. 持ち物チェック（かばん）
```

### バッチ2: 仕事・勉強（3×3で9個）

```
以下9個のアイコンを、3×3のグリッドで1枚に並べて生成してください。

1. メールを返す（封筒）
2. 資料をつくる（書類）
3. 会議（人が向かい合う）
4. 電話をかける（受話器）
5. 勉強する（本）
6. 書く（ペン）
7. パソコン作業（ノートPC）
8. 調べもの（虫めがね）
9. 提出する（送信）
```

### バッチ3: 家事（3×3で9個）

```
以下9個のアイコンを、3×3のグリッドで1枚に並べて生成してください。

1. 洗濯（洗濯機）
2. 干す（ハンガー）
3. 掃除（ほうき）
4. 料理（鍋）
5. 皿を洗う（食器）
6. ゴミを出す（ゴミ袋）
7. 買い物（買い物かご）
8. 片付ける（箱）
9. 支払い（請求書）
```

### バッチ4: からだ・休息（3×3で9個）

```
以下9個のアイコンを、3×3のグリッドで1枚に並べて生成してください。

1. 運動する（ダンベル）
2. 散歩（足あと）
3. お風呂（湯船）
4. 水を飲む（コップ）
5. 休憩（ソファ）
6. 寝る（月）

```

**「何もしない」を入れているのは意図的です。**休むことをタスクとして置けるのは、責めない世界観の表明になります。

## 3. 足りない分の扱い

ユーザーは自由にタスクを作るので、全種類を用意するのは不可能です。

- 用意した36個に該当しないタスクは **SF Symbols** から選ばせる（6,000種類以上あり無料）
- SF Symbolsを使う場合も、**丸い色付き背景に乗せる**ことで自作アイコンと馴染ませる
- 背景の丸とサイズ・余白を統一すれば、混在していても違和感は出ない

---

## 4. 生成後のチェック

並べて確認する。1つでも浮いていたら、そのバッチごと作り直す方が早い。

- [ ] 全アイコンで線の太さが揃っているか
- [ ] 余白（アイコンの周囲の空き）が揃っているか
- [ ] 縮小（40px程度）しても識別できるか
- [ ] ダークモードの背景に置いて沈まないか
- [ ] 決めたパレット以外の色が混ざっていないか
- [ ] 絵文字っぽく見えないか
